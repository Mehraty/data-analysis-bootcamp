# data-analysis-bootcamp
📚 6-Month Data Analytics Bootcamp Journey | سفر ۶ ماهه یادگیری دیتا آنالیز

### 🎯 About This Repository

This repository documents my journey through a **6-month intensive Data Analytics bootcamp**. It contains:

- 📝 **Weekly notes** — key concepts and learnings
- 💻 **Code exercises** — practice problems and solutions
- 📊 **Projects** — hands-on data analysis projects
- 📚 **Resources** — useful links and references

### 🛠️ Tech Stack

- **Languages:** Python 🐍, SQL 📊
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook, Git, GitHub
- **Database:** PostgreSQL, MySQL

### 🎓 Goals

- Master Python for data analysis
- Build a strong portfolio of projects
- Prepare for entry-level Data Analyst roles
- Share knowledge through documentation
